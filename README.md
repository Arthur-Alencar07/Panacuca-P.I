# Panacuca - Restaurante Italiano

Um site moderno criado para o Panacuca, um restaurante focado na autêntica culinária italiana, oferecendo pastas de qualidade e sabor artesanal.

## Sobre o Projeto

Este projeto consiste na página web (landing page/site institucional) do restaurante Panacuca. O objetivo é apresentar o ambiente do restaurante, destacar os principais pratos do cardápio e facilitar o contato e a reserva de mesas para os clientes. 

## Funcionalidades

* Apresentação do Restaurante: Seção dedicada à história e ao ambiente do Panacuca.
* Cardápio Digital: Exibição clara dos pratos principais, divididos por categorias (Entradas, Massas, Pizzas, Sobremesas).

## Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as tecnologias fundamentais da web, sem a dependência de frameworks externos pesados:

* HTML5: Estruturação semântica do conteúdo.
* CSS3: Estilização, layout (Flexbox) e animações em diversos elementos.
* JavaScript: Interatividade da página (como menus e carrosseis).

## Como executar o projeto

Para rodar este projeto na sua máquina localmente, siga os passos abaixo:

1. Clone este repositório:
   git clone https://github.com/Arthur-Alencar07/Panacuca-P.I.git

2. Navegue até a pasta do projeto:
   cd panacuca

3. Abra o arquivo index.html no seu navegador de preferência.
